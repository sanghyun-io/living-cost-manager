# 준비 키트 설계

## 목적과 비용
**가설:** 연간 구독을 직접 관리하는 사람이 다음 결제와 갱신 결정을 구분하는 데 이 제품이 도움이 되는지 먼저 확인한다. 방문자 확대나 절감 실적을 먼저 약속하지 않는다.

새 유료 리소스는 만들지 않는다. 기존 가이드 5개, 인증 후 수동 GSC 내보내기, 소규모 가상 데이터 인터뷰로 핵심 불확실성을 줄일 수 있다. 광고비·유료 SEO/분석 도구·CRM·추가 서버는 검증 전 고정비와 개인정보 처리 범위만 늘린다. 기존 자원의 여유 용량이나 무료 운영을 보장한다는 뜻은 아니다. 비용 증가가 필요하면 별도 Owner 승인부터 받는다.

## 소유권과 실행 경계
| 담당 | 산출/조건 |
|---|---|
| 마케팅 | 이 폴더의 카피·가설·질문·실험안; 공개 실행은 별도 승인 |
| 데이터 분석 | 근거 자료와 `evidence*`; 원본 출처·기간·누락·지표 검증 |
| runtime builder | 구현·로컬 검증 완료; 운영 승격 대기. 최종 계약은 [runtime 문서](../marketing-runtime.md) |
| 운영 도구 담당 | 캠페인 URL 생성기와 근거 CLI 구현됨; [링크 도구](../marketing-campaign-links.md), [근거 CLI 실제 명령](evidence-README.md) 참조 |
| Owner | 인증 GSC 자료 확보, 인터뷰 기록 단독 보관, 외부 활동 승인 |

GSC sitemap 수동 제출은 이미 완료되었다. 제출 성공은 색인·검색 유입 증거가 아니다. Dates.csv는 인증 대기이며 세션 우회·스크래핑하지 않는다. Dates.csv만으로 페이지별/검색어별 수요를 판정하지 않는다. 필요 시 Owner가 해당 차원의 별도 내보내기를 승인한다. 사용자 제공 배포 준비 검증상 기존 Pages 토큰은 프로젝트를 읽을 수 있으나 WebAnalytics metadata API는 403이다. analytics 설정·조회 결과는 접근 불가/미검증이며 트래픽 0이 아니다. 실제 지표 미확보 상태다.

운영 도구 입력/출력은 Git에서 무시되는 로컬 `marketing-private/`에 둔다. 디렉터리 mode `0700`을 권장하며 사용 전에 ignore·권한을 확인한다. Git ignore는 접근 통제가 아니다. 이 작업은 디렉터리 생성이나 권한 변경을 하지 않는다.

## 측정 계약 — 구현·로컬 검증 완료 / 운영 승격 대기
사용자 제공 결과: web 205 / API 141 / 브라우저 13개 시나리오 통과. coordinator 전체 검증·독립 리뷰 진행 중이며 운영 배포 증거는 아직 없다. 실제 지표·baseline은 unknown이다.
- 명시적 opt-in, 기본 off. 동의하지 않아도 핵심 제품 이용을 제한하지 않는다.
- 익명 일별 이벤트: `personal_cost_saved`, `personal_billing_date_saved`, `personal_renewal_decision_saved`.
- 대상은 서버에 연결되지 않은 로컬 개인 데이터의 명시적 사용자 작업이며 로컬 저장 성공 후에만 전송한다. 가져오기·복원·복제에 의한 신규 행, 샘플, 모든 서버 연결 프로필(로그아웃 후에도 연결된 프로필 포함), hydration·서버 조회·낙관적 UI 변경은 제외한다.
- `personal_cost_saved`: 이름과 명시적으로 입력한 유효 금액(명시적 0 포함)을 검증한 QuickAdd로 새 행을 만들고 로컬 저장에 성공한 경우만 해당한다. 빈 Add 행과 일반 수동 등록은 이벤트를 보내거나 이 마일스톤을 소진하지 않는다. 전체 등록·첫 가치 달성·금액 절약·결제 완료 지표가 아니다. 최종 기준은 [runtime 계약](../marketing-runtime.md)이다.
- `personal_billing_date_saved`: 명시적 편집으로 기준일이 유효한 달력 날짜로 변경되고 저장된 경우. 날짜 삭제·동일 값·카드 대금 결제일 설정은 제외한다.
- `personal_renewal_decision_saved`: 명시적 편집으로 유지·해지 예정·변경 검토·완료 중 하나로 변경되고 저장된 경우. 미검토는 제외하며 실제 해지·절감 증거가 아니다.
- 브라우저 동의 기간 내 이벤트명별 첫 마일스톤의 best-effort 중복 억제다. 매 저장·고유 사용자 집계가 아니며 동시 탭 경합, 저장소 초기화, 다른 브라우저·새 동의 기간으로 과대 집계될 수 있다. 전송 실패는 과소 집계, 위조된 공개 제출은 과대 집계 가능하다. 과거 기록 스캔·재전송 큐는 없다.
- ID 없이 일별 건수만 본다. 계정·워크스페이스·기기 식별자, 금액, 항목명, 실제 청구일, 자유 텍스트를 마케팅 지표에 넣지 않는다. 전송/접근 로그까지 개인정보가 없다고 단정하지 않는다.
- 브라우저/동의 기간이 다른 동일인을 구분할 수 없다. **고유 사용자, 퍼널 전환율, 재방문/리텐션, 절감액을 계산하지 않는다.** 이벤트 간 나눗셈도 사용자 전환율이 아니다.
- 서버 수신일 기준 UTC 집계이며 범위는 오늘 포함 **90 UTC 달력일(오늘−89일~오늘)**, 최초 실제 수집 시작일부터만이다. 과거 로컬 기록 backfill 없음. 도입 전 기간은 미측정이다. 실행 중 보존 정리는 구현되었지만 중지·비활성·실패 시 운영자가 만료 자료와 사본을 정리해야 한다. 실제 운영 설정·보존 이행은 별도 확인한다.
- opt-out은 이후 전송과 로컬 대기 작업을 중단하고 GPC/DNT가 동의보다 우선한다. 이미 받은 익명 집계에서 개인 건수만 뺄 수 없다. 저장소 오류 시 지속적인 철회 보장은 제한되므로 최종 계약의 GPC/DNT·사이트 저장소 안내를 따른다. 운영 경로·로그·접근 통제·보존 설정은 승격 전 확인한다.

현재 읽은 `apps/web/app/lib/analytics.ts:1–12`는 온디바이스 IndexedDB 기록이다. 이를 새 중앙 일별 측정의 구현·배포 근거로 쓰지 않는다. PM의 과거 전환/재방문 목표도 이번 익명 건수로 대체 측정하지 않는다.
