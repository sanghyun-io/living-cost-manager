## 먼저 할 일
1. Owner가 타깃·인터뷰 동의/보존안을 검토한다. 아직 모집·연락하지 않는다.
2. 인증된 GSC에서 **Dates.csv 다운로드 대기**를 해결한다. sitemap은 수동 제출 완료(사용자 제공 현황); 재제출 요청·스크래핑 없이 기존 자료를 확보한다.
3. 구현된 runtime의 [측정 계약](../marketing-runtime.md)과 [실제 검증·운영 릴리스 기록](../marketing-release-20261005.md)을 확인한다. 테스트 통과를 고객 가치나 유입 성과로 해석하지 않는다.
4. 구현된 [캠페인 URL 도구](../marketing-campaign-links.md)와 [근거 CLI 실행 안내](evidence-README.md)를 사용한다. 구현 사실이 캠페인 실행·성과 확보를 뜻하지 않는다.
5. 확보한 자료만으로 주간 판단한다. 실제 지표와 baseline은 여전히 `unknown`이다.

기능 근거는 코드·공개 가이드 원문·PM 및 릴리스 기록이다. 운영 준비에서 기존 Pages 자격증명의 프로젝트 조회는 성공했으나 WebAnalytics metadata API는 403이었다. 현재 자동화 권한으로 analytics 설정·집계는 미확인이며 트래픽 0을 뜻하지 않는다. 실제 마케팅 지표는 아직 확보하지 않았다.

공개 피드백 안내용 기존 링크: https://gamja.top/#contact — 계정·결제 정보 없이 사용 중 막힌 점만 설명하도록 안내한다. 수신자 정보나 응답 SLA는 공개/약속하지 않는다.

키트는 내부 자료 준비·검증용이다. 캠페인, 공개 게시, 고객 연락·이메일 및 과금은 별도 승인 후 실행한다.
