# 인터뷰 실행 전 준비안

**현재 인터뷰·모집·연락 없음.** Owner 승인 이후 첫 5회의 탐색 면담을 제안한다. 이는 통계적 검증 표본이 아니다. 조건은 여러 개인 구독과 연간 결제를 직접 관리하는지 여부이며, 회사·나이·실명·구독 서비스명·금액을 받을 필요가 없다. 최근 어려움이 없었다는 답도 그대로 기록한다.

## 시작 동의문 초안
“구독을 정리하는 방식과 안내의 이해도를 알아보려는 약 20분 면담입니다. 참여는 선택이며 질문을 건너뛰거나 언제든 중단할 수 있습니다. 실제 금융·계정 정보는 필요하지 않습니다. 가상 예시만 사용하며 녹음·영상·스크린샷은 남기지 않습니다. 동의하시면 Owner만 볼 수 있는 익명화 메모를 작성하고, 면담 후 30일 이내 삭제합니다. 개인을 알아볼 수 없는 내부 요약은 작성 후 90일 이내 삭제합니다. 공개 인용이나 후속 연락에 대한 동의는 포함하지 않습니다. 메모 작성에 동의하시나요?”

동의 전에는 기록하지 않는다. 거절하면 기록 없이 종료한다. 사용자 연락처, 이메일, 계정 ID, 로그인 화면, 비밀번호, 카드·은행·잔액·수입·거래 내역, 실제 결제일/금액, 백업 파일을 요청하지 않는다. 화면 공유도 필요 없다. 실수로 노출되면 기록하지 않고 이미 옮겨 적은 내용은 즉시 삭제한다.

## 비유도 질문 순서
1. 최근 구독을 계속 이용할지 생각했던 상황이 있었나요? 없다면 없다고 말씀해 주세요.
2. 그때 무엇을 확인했고 어떤 순서로 진행했나요? 서비스명이나 금액은 말하지 않아도 됩니다.
3. 현재는 어떤 방식으로 일정을 정리하나요? 별도로 정리하지 않으면 그 이유는 무엇인가요?
4. 현재 방식에서 편한 점과 불편한 점은 각각 무엇인가요?
5. 갱신을 확인할 필요가 없다고 느끼는 상황도 있나요?
6. 이 안내를 읽고 어떤 일을 할 수 있는 도구라고 이해했나요?
7. 안내에서 예상과 달랐거나 이해하기 어려운 부분은 무엇인가요?
8. 지금 쓰는 방식과 비교해 이 도구를 쓰거나 쓰지 않을 이유는 무엇인가요?

“돈을 아꼈겠죠?”, “유용하지 않나요?”, “얼마를 절약했나요?”는 묻지 않는다. 지불 의향 답변을 구매 전환으로 집계하지 않는다.

## 가상 데이터 관찰 과제
- 제품 화면 설명 전에 가상 구독(연간 120,000원, 기준일은 면담일, 12개월 주기)을 제시한다. 이는 설명용 금액이며 제품 요금·실제 재무 정보가 아니다.
- “이 예시를 도구에 정리해 주세요.” 도움 없이 등록/기준일 설정이 가능한지 관찰한다. 구조가 막히면 도움 제공 여부만 기록한다.
- “월환산 값과 30일 청구액을 각각 어떻게 이해했나요?” 정답을 먼저 알려주지 않는다.
- “이 예시는 다음 갱신을 원하지 않는 상황입니다. 다음에 무엇을 하겠어요?” 상태 저장과 사업자 해지를 구분하는지 관찰한다.
- 끝난 뒤 실제 해지나 금융 연동이 없음을 설명하고 가상 데이터 삭제를 안내한다. 과제 건수는 실제 사용자 행동/운영 절감과 합산하지 않는다.

## 기록·철회·삭제 계획
기록은 **Owner 전용 비공개 보관소**에만 둔다. 저장소·공개 문서·공유 분석 파일에 원문/고객 정보를 올리지 않는다. 보관소 권한 확인 전 수집하지 않는다.
