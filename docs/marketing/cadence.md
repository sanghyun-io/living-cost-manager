# 주간 의사결정 루틴

매주 월요일 30분, Owner가 결론을 남긴다. 실행 전 목표를 정하고 결과를 보고 유리하게 소급 변경하지 않는다. 첫 회에는 baseline을 **unknown**으로 둔다.

## 1. 자료 상태 확인 — 10분
- GSC: sitemap은 이미 수동 제출됨. 인증이 없으면 Dates.csv 대기로 기록하고 재제출/스크래핑하지 않는다. 받은 파일의 property, 검색 유형, 필터, 날짜 범위, 최신일의 완결 여부를 확인한다. 사이트 합계를 페이지/검색어 성과로 바꾸어 쓰지 않는다.
- runtime: [측정 계약](../marketing-runtime.md)과 [실제 검증·운영 릴리스 기록](../marketing-release-20261005.md), 수집 시작일·누락을 확인한 뒤 수치를 쓴다. 캠페인 URL 생성기와 근거 CLI: [링크 안내](../marketing-campaign-links.md), [CLI 실제 명령](evidence-README.md). 구현이 외부 실행 승인은 아니다. 입력/출력은 Git 무시 로컬 `marketing-private/`에 보관하고 mode `0700`을 권장한다.
- 기간: runtime은 수신일 기준 오늘 포함 90 UTC 달력일 안에서 최초 수집 시작 이후의 완결된 7일과 직전 7일을 비교한다. GSC와 일자 기준이 다르면 합치지 않는다. CLI에서 없는 날짜는 unknown이고 기존 날짜 행의 누락 이벤트 키만 0이다. 주간 합계는 7일 행이 모두 필요하다. 빈 날짜를 임의로 0으로 채우거나 backfill하지 않는다.
- 인터뷰: 동의·가상 데이터·도움 제공 여부와 삭제기한 확인. 기록은 Owner만 열람하고 분석 담당에게는 비식별 집계만 전달한다.

## 2. 해석과 결정 — 15분
`experiments.csv`의 기준으로 **유지 / 수정 / 중단 / 자료 대기** 중 하나를 고른다.

- 일별 세 이벤트는 미연결 로컬 개인 데이터의 저장 성공에 한한 브라우저 동의 기간 내 첫 마일스톤 제출 집계다. 고정비 이벤트는 이름과 명시적 유효 금액을 검증한 QuickAdd 신규 행만 해당하며 빈 Add 행·일반 수동 등록은 포함하거나 마일스톤을 소진하지 않는다. 전체 등록·첫 가치 달성 지표가 아니다. 유효 기준일 변경·갱신 결정 변경의 저장 성공 조건은 그대로이며 [최종 runtime 계약](../marketing-runtime.md)을 따른다. 가져오기·샘플·서버 연결 프로필(로그아웃 후 포함)은 제외한다. best-effort 중복 억제로 동시 탭 과대 집계가 가능하다. 매 저장이나 사용자 수가 아니며 고유 사용자·퍼널·리텐션을 만들지 않는다. 검색 클릭과 나눠 전환율로 쓰지 않는다.
- opt-in 선택 편향, 브라우저/동의 기간 변경, 구현 변경, 누락 때문에 건수 증감만으로 제품 가치/카피 효과를 결론내리지 않는다.
- 검색 CTR은 합계 클릭/합계 노출로 계산하며 일별 CTR 단순 평균을 쓰지 않는다. 0노출은 N/A, 작은 표본은 판단 유보. 현재 검색량/순위/경쟁도 baseline도 미확보 상태다.
- 같은 혼동이 반복되면 기존 가이드 한 부분의 수정안을 준비한다. 외부 반영은 별도 승인이고 한 번에 여러 카피를 바꾸지 않는다. 전후 비교는 인과 실험이 아니다.
- 개인정보 유입·동의 위반·부정확한 기능 약속을 발견하면 관련 실험을 중단하고 Owner 검토부터 받는다.

## 3. 다음 행동 — 5분
다음 주까지의 작업은 최대 2개로 제한한다. 담당·기한·선행 조건을 기록한다. 고객 연락/이메일/공개 게시·캠페인은 이 루틴이 자동 승인하지 않는다. 운영 준비에서 기존 Pages 자격증명의 프로젝트 조회는 성공했으나 WebAnalytics metadata API는 403이었다. 현재 자동화 권한으로 analytics 설정·집계는 미확인이며 트래픽 0으로 쓰지 않는다. 실제 지표는 미확보다.

### 내부 결정 메모 양식
```text
주차 / 검토일:
자료 출처 / 관측 기간 / 시간대 / 수집 시작일:
미확보·결측 / baseline:
관찰 사실(분자·분모 또는 일별 건수):
해석 가설 / 반대 설명:
결정(유지·수정·중단·대기) / 이유:
다음 행동 1~2개 / 담당 / 기한 / 승인 필요 여부:
인터뷰 삭제기한 점검 결과:
```

원자료·개인 사례를 이 양식에 복사하지 않는다. 최초 판단은 성과 보고가 아니라 자료 가용성과 검증 준비 상태 보고다.
