# 브라우저 QA 요약 — LCM UI 콘셉트 10선 (2026-10-20)

정적 HTML 산출물(`index.html` + `concept-01..10.html`)에 대한 로컬 헤드리스 브라우저
검증 결과의 **비공개 경로·환경 정보를 제거한 고수준 요약본**입니다.
원시 실행 로그(JSON)와 검증 스크립트, 최초 라운드 스크린샷은 이 아카이브에 포함하지
않습니다(검증 환경 참조 및 패치 전 상태 기록 목적). 아래 숫자와 판정은 실제 실행
결과를 그대로 정리한 것입니다.

## 방법 (개요)

- 이미 설치된 로컬 도구로 정적 파일을 `file://`로만 렌더링 확인. 외부 네트워크 요청
  시도 0건(차단·계측). 원격 폰트/CDN/이미지 없음은 HTML 정적 검사와 실제 요청
계측 양쪽에서 확인했다.
- 브라우저 프로필은 합성 임시 프로필만 사용했고 검증 후 삭제 확인. 사용자의 실제
  브라우저 프로필·탭·확장에는 접근하지 않았다.
- 산출물 HTML 자체는 QA 중 수정하지 않음(QA 시작 이전 mtime 확인).

## 1차 결과 — 75케이스: 72 PASS / 3 FAIL (전량 통과가 아님)

실패 3건의 판정과 조치:

1. **concept-02 @390px 가로 넘침** (실제 FAIL): 문서 scrollWidth 617 > 390.
   원인: `1fr` 그리드 트랙의 auto 최소너비와 너비 고정(`nowrap`) 표.
   → 이후 패치: `minmax(0,1fr)` 전환, 표 4개를 가로 스크롤 가능한 영역 래퍼로 감쌈,
   세그먼트 탭 최소높이 44px. **r2 재검 PASS, CLOSED.**
2. **concept-09 합성 데이터 고지(note) 미표시** (실제 소견): CSS 선언 순서 오류로
   데스크톱에서도 면책 고지가 `display:none`.
   → 이후 패치: 기준 규칙을 미디어 쿼리 앞으로 이동. r2에서 1440px 표시·390px DEMO
   배지 확인. **CLOSED.**
3. **index 포커스 케이스** (테스트 하네스 아티팩트, 실질 PASS): Tab 이동을 미리보기
   iframe이 흡수한 것이 계측 왜곡의 원인. iframe을 제외하고 재검한 결과 실제 컨트롤
   4/4에서 가시 포커스 링(`outline: solid 3px`) 확인. 산출물 수정 불요.

## 알려진 참고 사항 (advisory — 차단 아님, 채택 시 후속 패치 대상)

- 일부 텍스트 링크·세그먼트 탭의 탭 대상이 44px 미만(모바일). 제안서 수준에서는
  허용 범위로 판정했으나, 실제 제품 구현에서는 최소 44px 적용 필요.
- concept-07 달력: 격자의 요일·날짜 배치는 2026년 10월 실달력과 일치(10.1 목,
  10.20 화, 10.25 일, 10.31 토)하고 "오늘"도 10.20에 정확히 표시. 다만 10.19와
  10.25 셀에도 `today` 강조 클래스가 함께 걸려 있어 오늘 하이라이트가 3개 셀로
  보이는 장식적 오류가 있음. 아카이브본은 원본 바이트와 동일하게 보존했고
  (해시 검증), 채택 결정 시 1회 패치로 정리할 것.
- concept-03 슬라이더: 첫 입력 시 표시 대상 id가 innerHTML 갱신으로 소멸 — 표시
  자체는 계속 정상 갱신되므로 목업 수준에서는 무해.
- 미리보기 iframe 자체의 포커스 링 없음(장식적).
- 모든 셀렉트/월 이동/구성원 필터는 목업 상태 표시(비동작)가 라벨·aria에 명시됨.
