## 보는 방법

GitHub의 소스 브로즈는 HTML 페이지를 **렌더링하지 않고 코드만 표시**합니다.
따라서 보려면:

1. 이 저장소를 clone(또는 폴더를 다운로드)한 뒤,
2. Finder/파일 관리자에서 `index.html`을 **더블클릭해 브라우저로 열면** 됩니다.
   `index.html`이 10개 콘셉트의 비교 갤러리이며 상대 경로로만 참조하므로
   폴더 전체를 그대로 가져오면 인터넷 없이(`file://`) 완전히 동작합니다.
   개별 `concept-NN.html`만 직접 열어도 됩니다.

이 아카이브를 GitHub Pages 등으로 **공개 배포하지 않았습니다**(범위 밖 작업).
시각 QA 증거는 [`qa/README.md`](qa/README.md)와 `qa/shots/`(r2 재검 5장)에,
파일 무결성 해시는 [`manifest.sha256`](manifest.sha256)에 있습니다.

## 합성 데이터 기준값 (canonical fixture)

모든 콘셉트가 공유하는 합성 기준 수치(문서화된 픽스처, 실제 계좌·부채와 무관):

- 월 예산: 1,284,000원
- 이번 주 배분 180,000원 / 사용 64,500원 / 잔여 115,500원
- 비상금·예비금 계열: 720,000원 / 420,000원 / 300,000원

일부 화면에는 슬라이더·주 선택 데모에서 파생되는 표시값(예: 15,500 / 184,500 /
1,415,700원)이 등장하며, 데모 인터랙션에 따른 합성 계산 표시일 뿐입니다.

## 검증

- `manifest.sha256`: 보관된 각 파일의 SHA-256과 바이트 수 목록.
  11개 HTML(index + concept-01..10)의 해시는 원본 산출물 바이트와 대조해
  동일함을 확인했다.

  없음): `node verify-archive.mjs` 실행 시 해시 대조 + 내부 링크·앵커 실존 여부 +
  외부 요청 금지 규칙을 점검합니다. 이 스크립트는 아카이브 자체의 무결성
  확인용이며 앱 런타임 경로가 아닙니다.
